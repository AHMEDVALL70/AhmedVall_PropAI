# دليل نشر منصة أحمد فال — إصلاح أمان المفتاح

هذا الدليل يشرح خطوة بخطوة كيفية جعل مفتاح Claude API مخفياً بالكامل عن أي زائر لموقعك.

## الفكرة باختصار

قبل الإصلاح: المتصفح ← (مفتاحك) ← Anthropic API
بعد الإصلاح: المتصفح ← الخادم الخلفي (فيه المفتاح كسرّ) ← Anthropic API

الزائر لا يرى المفتاح أبداً في أي من الحالتين بعد الإصلاح، حتى لو فتح أدوات المطوّر.

---

## الخطوة 1: نشر الخادم الخلفي على Cloudflare Workers (مجاني)

1. أنشئ حساباً مجانياً على [dash.cloudflare.com](https://dash.cloudflare.com) إن لم يكن لديك.
2. على جهازك، ثبّت أداة النشر:
   ```
   npm install -g wrangler
   ```
3. سجّل الدخول من الطرفية:
   ```
   wrangler login
   ```
   سيفتح لك نافذة متصفح لتسجيل الدخول بحساب Cloudflare.
4. أنشئ مجلداً جديداً وضع بداخله ملف `worker.js` المرفق، وأنشئ بجانبه ملف باسم `wrangler.toml` بهذا المحتوى بالضبط:
   ```toml
   name = "ahmedvall-propai-backend"
   main = "worker.js"
   compatibility_date = "2024-01-01"
   ```
5. أضف مفتاح Claude كسرّ (لن يُكتب في أي ملف أو يُرفع على GitHub):
   ```
   wrangler secret put ANTHROPIC_API_KEY
   ```
   الصق مفتاحك (يبدأ بـ `sk-ant-`) عند الطلب واضغط Enter.
6. انشر الخادم:
   ```
   wrangler deploy
   ```
7. ستظهر لك رسالة تحتوي رابطاً شبيهاً بهذا:
   ```
   https://ahmedvall-propai-backend.<اسمك>.workers.dev
   ```
   احتفظ بهذا الرابط.

---

## الخطوة 2: ربط الموقع بالخادم

1. افتح ملف `index.html`.
2. ابحث عن هذا السطر (قرب بداية قسم `<script>`):
   ```js
   const BACKEND_URL = 'https://REPLACE-WITH-YOUR-WORKER-URL.workers.dev/chat';
   ```
3. استبدله برابطك الفعلي من الخطوة السابقة + `/chat` في النهاية:
   ```js
   const BACKEND_URL = 'https://ahmedvall-propai-backend.اسمك.workers.dev/chat';
   ```
4. احفظ الملف وارفعه إلى GitHub Pages كالمعتاد (استبدال الملف القديم بالكامل).

---

## الخطوة 3 (مهمة أمنياً): تقييد الوصول لدومين موقعك فقط

في ملف `worker.js`، ابحث عن هذا السطر بالأعلى:
```js
const ALLOWED_ORIGIN = "*";
```
غيّره إلى دومين موقعك الفعلي فقط بعد التأكد أن كل شيء يعمل، مثلاً:
```js
const ALLOWED_ORIGIN = "https://ahmedvall70.github.io";
```
ثم أعد النشر:
```
wrangler deploy
```
هذا يمنع أي موقع آخر من استخدام خادمك (وبالتالي رصيدك في Claude API) دون إذنك.

---

## التحقق من نجاح الربط

افتح موقعك، اذهب لتبويب "المستشار العقاري الذكي"، واسأل أي سؤال. إن ظهر رد حقيقي متصل بالسياق (لا رد جاهز مكرر)، فالربط ناجح. إن ظهرت رسالة تعذّر الاتصال، تأكد من:
- أن الرابط في `BACKEND_URL` صحيح وينتهي بـ `/chat`
- أنك نفّذت `wrangler secret put ANTHROPIC_API_KEY` بنجاح
- أن رصيد حسابك في Anthropic Console كافٍ
